browser-pilot — 面向 agent 的受控浏览器操作工具

最简用法：
  browser-pilot run 脚本.json

  第一次运行会开一个 Chrome 窗口，你在里面登录一次；之后所有脚本都复用这个登录态。
  窗口关了再打开，登录态还在（配置目录：%LOCALAPPDATA%\browser-pilot\profile）。

  脚本需要账号密码、而该站点没登录过时，会弹一个小窗口问，
  可勾选「长期保留」——那会用 Windows DPAPI 加密存到
  %LOCALAPPDATA%\browser-pilot\creds.json，只有本机当前用户能解开。

  脚本只是打开页面、截图、取文字时，它一个字都不会问。

其它用法：
  browser-pilot run <script.json> [选项]

选项：
  --out <dir>         输出目录（默认 ./.bp-out/<时间戳>）
  --ephemeral         零留痕模式：每次全新内存上下文，不落 Cookie 与历史
  --headed            显示浏览器窗口（共享模式下窗口本来就是可见的）
  --profile <dir>     指定共享浏览器的配置目录
  --cdp-port <n>      共享浏览器调试端口，默认 9222，冲突时换一个
  --channel <name>    chrome（默认）| msedge
  --timeout <ms>      单步默认超时，默认 15000
  --creds-file <p>    从 JSON 文件读凭据 {user, pass}
  --creds-stdin       从标准输入读凭据（JSON，或一行「账号|密码」）
  --no-gui            不弹图形窗口
  --no-prompt         缺少凭据时不要询问，直接报错（适合 CI）
  --no-audit          跳过留痕自检（不推荐，仅供调试）

何时会问你要账号：
  站点已在共享窗口登录                       不问，直接用
  login 动作 + 该站点记住过                  不问，自动取
  login 动作 + 没记住过                      弹窗问（可勾选长期保留）
  { "valueFrom": "user" } / "pass"           只问缺的那个
  其余（打开网页、截图、取文字、点击、滚动）  完全不用凭据

凭据来源优先级：
  --creds-stdin > --creds-file > 环境变量 BP_CREDS / BP_USER+BP_PASS
  > 该站点记住的（DPAPI）> 图形弹窗 > 终端询问

  凭据永远不写进脚本文件，脚本可以安全提交进 Git。

脚本格式（JSON）：
  {
    "url": "https://example.com/login",
    "steps": [
      { "type": "goto",  "url": "https://example.com/login" },
      { "type": "login", "userSelector": "#user", "passSelector": "#pass",
        "submitSelector": "button[type=submit]" },
      { "type": "wait",  "ms": 2000 },
      { "type": "shot",  "name": "01-after-login" },
      { "type": "text",  "selector": "h1" }
    ]
  }

动作类型：
  goto       打开网址            url, waitUntil
  wait       等待                ms / selector / text + state + timeout
  shot       截图                name, fullPage
  click      点击                selector / text / role+name / placeholder / label, force
  dblclick   双击                同上
  fill       填空（含 contenteditable）  同上 + value / valueFrom, force
  type       键盘逐字输入        value, delay
  selectall  全选当前焦点内容    —
  press      按键                key（默认 Enter）
  login      登录组合            userSelector, passSelector, submitSelector
  text       取文字              定位（不给取 body）, max
  dom        取元素 HTML         定位, max
  probe      列元素信息          selector, max
  bbox       取元素坐标尺寸      定位
  count      元素计数            selector
  title      取标题              —
  url        当前网址            —
  urlhost    只取主机名          —
  frames     列框架主机名        —
  neterrors  列失败请求          max
  scroll     滚动                y
  clickxy    按坐标点击          x, y（坐标会随窗口尺寸/缩放失准，优先用选择器）

退出码：0 成功 / 1 有步骤失败 / 2 用法或凭据错误 / 3 留痕自检失败
