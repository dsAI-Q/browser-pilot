# 安全模型

这个工具的存在前提是：**让 agent 能操作浏览器，同时把「留什么、不留什么」说清楚，并且由你选。**

## 〇、两种模式，边界不同

| | 默认：共享浏览器 | `--ephemeral`：零留痕 |
|---|---|---|
| 登录态 | **保留**，在 `%LOCALAPPDATA%\browser-pilot\profile`（或 `--profile` 指定目录） | 不保留，进程结束即销毁 |
| Cookie / 浏览历史 | 由 Chrome 自己管理，会写入该配置目录 | 只在内存里 |
| 适合 | 日常使用：登录一次，之后 agent 全程自己干 | 临时查资料、不想留任何痕迹 |
| 输出侧脱敏 + 跑完自检 | ✅ 同样执行 | ✅ 同样执行 |

**所以「零留痕」是 `--ephemeral` 的性质，不是默认行为。** 默认模式刻意保留登录态——否则每跑一次都要你重新登录，工具就没法用了。想清掉随时删那个目录。

## 一、威胁模型

| 风险 | 本工具的处理 |
|---|---|
| 浏览历史被写到磁盘 | `--ephemeral` 下只用 `browser.newContext()`；**不使用 `launchPersistentContext`** |
| Cookie / 登录态被保存 | `--ephemeral` 下上下文关闭即销毁，不导出 `storageState` |
| 网络请求被录制 | 两种模式都禁止 `recordHar`（代码层面拒绝启动） |
| 过程被录屏 | 两种模式都禁止 `recordVideo`、`tracing` |
| 账号密码被写进脚本或日志 | 凭据只在运行时注入；脚本文件里只有选择器 |
| 账号密码被记住后泄露 | 「长期保留」用 Windows **DPAPI** 加密，只有本机当前用户能解；文件在 `%LOCALAPPDATA%\browser-pilot\creds.json` |
| 网址出现在输出文件里 | 输出前统一脱敏为 `<url>`；manifest 只存站点主机的不可逆哈希 |
| 凭据出现在错误信息里 | 所有错误信息先过脱敏器 |

## 二、三道防线

**第一道：启动时拒绝危险选项**

`src/policy.mjs` 的 `assertZeroRetention()` 会在创建上下文前检查
`recordHar` / `recordVideo` / `storageState` / `video` / `har`。
只要有人传进来，直接抛错，浏览器不会启动。

**第二道：写盘前全量脱敏**

所有离开内存的内容（stdout、`steps.json`、`manifest.json`、错误信息）
都必须经过 `src/redact.mjs` 的 `makeRedactor()`：

- 本次使用的账号 / 密码明文 → `<cred>`
- 任意 `http(s)/ws(s)/ftp` URL → `<url>`
- 邮箱 → `<email>`
- IPv4 → `<ip>`
- `token=` / `password:` 这类键值 → `<redacted>`

**第三道：跑完自检**

`auditNoLeak()` 会扫描输出目录里的所有文本文件，
确认没有本次用到的网址或凭据原文。**发现即报错，退出码 3。**

这道自检的意义是：不让你相信我「没有记录」，而是每次跑完都能看到扫描结果。

## 三、明确的边界

**本工具不做也不打算做的事：**

- **不接管你已经登录的那个 Chrome**：Chrome 136+ 禁止对默认配置目录开调试端口，外部程序无法接管普通启动的浏览器。所以工具用自己维护的一个窗口（登录一次，之后复用）
- 不在后台常驻、不注册开机启动（浏览器窗口关了，下次运行会自动重开）
- 不上传任何数据到任何服务器
- 不收集遥测、不统计使用情况、不读取系统里其他浏览器的数据

**使用者需要自己保证的：**

- 你有权操作你指定的那个网站与账号
- 你遵守目标网站的服务条款与 robots 策略
- 不要在脚本里硬写密码（用 `valueFrom` + 运行时注入）
- 不想留任何登录态就用 `--ephemeral`

## 四、截图的边界

截图是像素数据，**可能包含页面上的账号、邮箱、订单号等个人信息**。
本工具无法对图片做脱敏。

因此：

- 截图默认落在 `.bp-out/`，该目录已在 `.gitignore` 里
- **提交代码或分享输出目录前，请自行检查截图内容**
- 如果你要开源自己的脚本，只提交 `examples/` 下的脚本 JSON，不要提交输出目录

## 五、报告问题

发现脱敏漏洞（例如某种格式的网址没被替换掉），
请附上**脱敏后**的最小复现，不要附真实网址或账号。
